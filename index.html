【AIショート動画メーカー｜使い方】

台本を入れるだけで、顔出しなしの縦型ショート動画が作れるツールです。
AI音声・AI背景・字幕・サムネまで全部自動。追加課金もAPIキーも不要です。

■ 準備（初回だけ）
1. Zipを解凍する
2. 必要ソフト：Node.js / Python / FFmpeg（未導入なら先に入れる）
3. 解凍したフォルダをターミナルで開いて、下を実行：
   pip3 install gtts
   cd app
   npm install
   cd ..

■ 使い方（1本つくる）
1. script.json に台本を書く（テーマとセリフだけでOK）
2. python3 scripts/generate.py   ← 音声と背景を自動生成
3. cd app
   npx remotion render src/index.ts FacelessShort ../output/動画.mp4
→ output フォルダに完成した動画ができます

■ 自分好みに育てる
settings.json を書き換えると、声・BGM・文字色・フォント・背景トーン・話速を
全動画にまとめて反映できます。使うほど自分仕様になります。

ターミナルのコマンドを自分で調べて打つ必要はありません。フォルダを渡して、こう頼むだけです。

Zipを解凍する

2
そのフォルダをClaude Codeのチャットにドラッグする

ドラッグできないときは、フォルダの場所（パス）をチャットに貼るだけでもOK。

3
こう頼む（初回だけ）

このフォルダの SETUP.md を読んで、その手順どおりに環境構築を進めてください
4
1本つくる

台本（script.json）を書いたら、書き出しも頼めば代わりに実行してくれます。完成した動画は output フォルダに入ります。

script.json の台本で、ショート動画を書き出してください
エラーが出たら、そのまま貼るだけ — 赤い文字が出ても自分で原因を調べなくて大丈夫です。表示された文章をそのままClaude Codeに貼って「これ直して」と伝えれば、続きから進めてくれます。

Claudeは絵を描かない。発注する。

このスキルの肝は、Claude自身が画像も音声も生成しないこと。Claudeは台本と指示文を書き、無料の外部サービスとローカルツールに“発注”するだけ。だから $0 で回る。

① 設計

台本づくり

字幕・強調ワード・背景プロンプト・サムネをClaudeが執筆。

② 音声

gTTS

セリフを自然な日本語ナレーションに。

無料・キー不要
③ 背景

Pollinations

シーンの内容に合ったAI画像を1枚ずつ生成。

無料・キー不要
④ 合成

FFmpeg + Remotion

背景＋字幕＋音声＋ズームを縦型9:16のMP4に。

要するに — Claudeは「絵を描く人」ではなく「絵を描いてくれる無料サービスに発注するプログラムを書いて動かす人」。だからキーも課金もいらない。

使う人ごとに、育つ

理想の動画は人それぞれ。最初はこの形ですが、使いながら「こうしてほしい」と伝えるほど、あなた専用の形に近づいていきます。むずかしい設定はいりません。

「もっと落ち着いた声にして」→次からの動画ぜんぶが、その声に
「このBGMを流して」→毎回、そのBGMが自動でつく
「文字をピンクにして」→強調の色が、ずっとピンクに
